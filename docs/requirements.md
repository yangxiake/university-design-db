# 高校 PPT 资料库：需求与验收

版本：2026-10-02。按用户最新决定：范围保持全部本科；采集收窄至原始PPT主字段，剔除无用且维护成本高的数据。

## 用途与范围

提供给个人及 AI 助手制作高校主题 PPT 使用的初步整合资料库，包含事实、视觉设计依据、官方和社区资源入口。

- 教育部 2026 年普通高校原表：2,952 所，保留身份及出处。
- 本科档案范围：原表 `level=本科` 的全部 1,412 所，无其他选校过滤，包括职业本科、民办和合作办学。名单不含军校，原先排除的三所军校不额外加入。
- 第二轮双一流标签：在教育部范围内匹配 144 所，作为优先补采和检索标签。
- 所有本科院校建立单校档案。逐字段尽力补采；保留缺口、访问失败与来源差异，不为填满字段推测事实。
- 公开 GitHub 资料可下载检查并纳入有来源的有效信息。只读，不执行上游代码。允许再分发的数据子集保留独立许可；无许可资源保存链接和版本。

## 分类与层级

`universities/<教育部省级分组>/<学校标识码>/profile.yaml` 为唯一事实源。每校只有一个档案，不因标签建立副本。

主类别按双一流、职业本科、合作办学、民办、其他本科依次归类；主类别互斥。标签保留全部命中属性，可同时为职业本科与民办。职业本科标签依据校名“职业大学/职业技术大学”规则，民办、合作标签依据教育部备注；规则及原始备注公开，不扩大成未获证明的学校性质判断。

地区、类别、重叠标签、采集状态索引均从范围表和档案生成。第三方资料按来源仓库组织在 `data/external/`，单校资源在本校 `resources.community_resources` 中引用。

## 主字段与可选材料

唯一范围清单位于 `data/ppt-core-fields.yaml`，当前档案结构为 v4。

| 层级 | 保留内容 | 补齐要求 |
| --- | --- | --- |
| 学校身份 | 教育部中文校名、标识码、省市、层次、主管部门、备注和分类；英文名 | 必备，身份与原表一致；英文名附来源 |
| PPT视觉 | 至少一个读到实际文件的校徽、校名或徽名组合；主题主色及方法 | 必备，校方标准与PPT建议色分开 |
| PPT文字 | 建校年及历史起点口径 | 必备，不以更名年或推测文本填空 |
| 来源支持 | 官网、简称与别名、从身份字段生成的短简介 | 供取证、检索与快速使用 |
| 可选丰富 | 校训、辅色/色卡、VI手册、校徽简述、校史节点、校园意象、校花/吉祥物/校歌、官方及开源模板 | 同源遇到时补充；空值不阻碍主字段验收 |

招生分数与计划、就业报告与指标、历史排名、学科评估/授权、人数、面积、科研、生源、地址坐标、电话邮箱等从当前档案、派生索引与上游数据子集剔除。停止主动采集和定期维护这些数据。旧提交是历史记录，不成为现行资料入口。

校徽、标识和模板只保存链接与元数据。必要的格式、尺寸、透明情况、文件/包内成员哈希、取值依据、版本、日期和独立使用规则保留，便于用户及AI正确取用。来源与权利元数据属于主字段质量要求。

自动资料为 `verified: auto`，单校采集状态为 `auto_collected`。人工核验可在后续进行，本轮不要求签核，也不将 AI 采集标为人工核验。社区资源的配色不得导入为校方标准色。

## 本轮验收

1. 1,412 个档案与教育部本科名单逐一对应，身份键唯一，官方附件哈希可复核。
2. 所有正向事实、资源条目保留直接来源、采集日期及来源/方法标记。第三方数据有上游提交和许可记录。
3. 访问错误尝试可用的不同网址；保留已尝试地址和结果。当前缺口、冲突、社区资料差异公开报告。
4. 1412份v4主字段档案的分类、索引、PROFILE/VISUAL/OFFICIAL/COMMUNITY生成视图一致；`validate_profiles.py --automatic-draft`与生成一致性检查通过。主字段覆盖报告与补采队列从同一字段清单生成。
5. 主字段逐校补齐状态须由 `ppt-core-coverage-2026.json` 计算，不能用可选字段数量或档案数量代替。存在未解缺口时如实列出，不宣称全部补齐。
6. 发布为明确标识的自动采集资料版本，不宣称所有字段已完备或已人工审定。未来人工审定版本另用可选的 `--release` 检查。
