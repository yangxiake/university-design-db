# 高校 PPT 资料库：产品需求与发布门槛

版本：2026-09-30 评审版。历史方案保留在用户提供的 WorkBuddy 原目录；本文件以新版范围和后续决定为准。

## 用途

为个人和 AI 助手制作高校主题 PPT 提供可检索、可追溯的事实与官方资源入口。这里是资料库，不是 PPT 成品、模板镜像或自动生成器。

## 范围

- Tier 0：教育部 2026 年普通高校名单 2952 所，保存其学校标识码、名称、省级分组、所在地、办学层次、主管部门、备注和来源。
- 深加工范围：933 所，含教育部名单中的 144 所第二轮“双一流”高校和 789 所其他入选高校。国防科技大学、海军军医大学、空军军医大学不在范围内。范围身份键是教育部学校标识码。
- 933 所须逐校核查，记录颜色与方法、建校年与口径、校史文化、官方 PPT 资源入口与使用规则；没有发现时留检索记录，来源冲突时保留候选值。不得为了填满字段臆测事实。
- 仅收文字事实、链接和简短摘要；不收校徽、照片、字体或官方模板文件。

## 分类与目录

地理层级以教育部名单的省级分组为准，档案路径为 `universities/<省级地区>/<学校标识码>/profile.yaml`。中文校名、代码和地区都可在 `indexes/catalog.csv` 中查找。地区、办学层次、教育部备注、互相重叠的范围标签、排他的筛选类别和研究状态是独立维度，不建立第二套档案。

`scope_category` 是筛选流程的排他类别，不代表学校的官方属性。特别是“其余未备注本科”只表示教育部原表备注栏为空，不能推断办学性质。`scope_tags` 用于交叉筛选，一所学校可同时有多个标签。`indexes/` 全部由唯一范围表与档案生成。

## 单校数据

- `identity`：教育部身份字段，以及有来源的英文名、官网。
- `classification`：范围纳入原因和标签，作为检索元数据。
- `visual`：标准色、来源/取色方法、VI 入口、校徽文字描述、校园意象。
- `culture`：建校年及历史起点、校训、校史节点、校花等。
- `resources`：官方 PPT 入口、发布方、规则摘要。`OFFICIAL.md` 由档案生成。
- `research` 和每字段元数据：区分未调查、找到、检索后未找到、来源冲突；区分自动提取和人工复核，并记录来源、核查日期。

字段结构详见 [schema.md](schema.md)，AI 使用流程详见 [data-guide.md](data-guide.md)。

## 验收与公开发布

1. 官方附件及用户选校输入可按校验和重建 2952 条 Tier 0 和 933 条范围表；三所军校为零，所有标识码唯一。
2. 933 所逐校完成调查；所有正向事实有来源与核查日期，关键缺失有检索记录，冲突明确列出。
3. 每校人工签核，已录事实标记 `verified: human`；官方资源及其使用规则核对。发布覆盖率报告，区分档案数、已调查数、人工签核数、PPT 就绪数。
4. 校验器、生成视图和索引一致性检查通过。公开仓库、正式版本和对外宣称完整交付均以第 2、3 步为前提。

当前仓库是**可审阅的资料底座**：范围表覆盖 933 所，只为已开始调查的学校建档。索引中的空 `profile_path` 表示尚未建档。用户已选择“先完成可复核资料，人工签核后发布正式版”。
