# 主字段补齐与维护计划

历史计划快照。后续已暂停主动补采，以下计划不表示正在执行或已实现；当前状态见[仓库首页](../README.md)与[版本记录](../CHANGELOG.md)。

日期：2026-10-03。当前范围为教育部2026名单中的1412所本科院校，军校不加入。字段范围已按用户决定收窄为PPT主字段，当前档案结构v4。

## 当前任务

1. 补齐英文校名、建校年及历史起点口径、可读校徽/校名标识、附依据主题主色。
2. 先读官网简介、章程、英文主页与视觉规范；访问失败尝试正常公开的不同网址。
3. 使用固定版本开源数据及有效社区资料补缺。完整现校名必须匹配，来源、版本、日期及实际读取结果保留。
4. 校方数字色、标识取色、网站配色与社区模板色分开。建议色注明PPT用途，来源冲突保留。
5. 每批串行导入单校档案，重建七项派生内容并运行统一校验；更新逐校缺口队列后提交GitHub。

不再采集招生、就业、排名、动态人数、面积、联系方式及学科统计。校训、模板、VI、校史节点等为可选资料，空缺不计入主字段完成条件。
