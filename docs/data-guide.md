# 人和 AI 助手如何使用资料

1. 查 `indexes/catalog.csv`，用学校标识码定位 `profile_path`。该列为空表示尚未建档。遇到同名或更名时，以代码和教育部原表身份字段核对。
2. 读取档案中的 `availability`、`verified`、`source` 和 `checked_at`。在正式学校主题 PPT 中，只把 `found` 且 `human` 的字段写成已确认学校事实，并在备注或参考页保留来源链接。
3. `auto` 是待复核线索。`conflict` 要展示冲突并停止采用该字段；`unresearched` 与 `not_found` 都不能改写成“学校没有”。
4. 颜色若为 `badge_sample` 或 `manual_derived`，在设计说明中写“建议色”及方法；不能称为官方校色。没有可靠色值时可用中性配色。
5. 官方模板与校徽等资源只给入口。下载或使用前核对来源页面的适用对象和规则；链接可失效，发现失效请提交修订。

目前自动提取正在扩展，但所有新增字段均未人工签核。需要立即制作 PPT 时，可用教育部身份字段说明学校名称与地区，并自行访问学校官网复核具体文化和视觉事实。此库当前不具备全校特色 PPT 直接生成的质量门槛。
