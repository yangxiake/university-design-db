# 2026-10-03素材目录界面更新

版本：`v0.4.3-20261003`。按用户要求暂停未完成的数据补采，本轮优化现有素材目录的搜索与信息层级。

网页不再显示“短校名”“校名以大学结尾”“教育部备注为空”等采集分类，也不再提供分类标签筛选。主搜索入口改为校名、地区和素材类型，直接选择学校标识、配色或PPT素材。常用格式、来源、标识样式等条件放入“更多筛选”，折叠时显示已启用的条件数，重置时自动清空并收起。旧地址中的`tag`参数不再生效，首次打开会自动清理。

页头收紧，学校列表增加明确标题，筛选文字更易理解；桌面与手机沿用现有深绿色风格。来源、核验记录、使用条件与单校JSON继续保留。HTML、未知格式与示例标记不作为文件格式选项，原记录仍能从详情与JSON查看。

浏览器实测英文简称检索、旧标签地址、来源与格式必须匹配同一素材、刷新恢复、切换素材类型、重置，以及1280×900桌面和390×844手机布局。手机没有横向溢出。统一质量检查13/13通过，包含130项Python测试和13项网页规则测试；不宣称完整无障碍合规或全量远程图片永久可访问。

学校事实、主字段覆盖和剩余缺口沿用v0.4.2：1412所本科院校，1380所主字段齐备，剩余32所、59项。本轮没有补入新事实或第三方图形。使用方法见[素材目录说明](../viewer-guide.md)。
