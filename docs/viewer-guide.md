# 素材目录 v1

## 打开和使用

在下载后的仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开`http://127.0.0.1:8765/viewer/`。静态页面没有npm依赖，也不需要Node.js。通过HTTP读取JSON，直接双击HTML的`file:`方式无法正常载入数据。可部署到支持静态文件的HTTP服务；当前交付在现有私有GitHub仓库，未开通公共站点。

1. 搜索校名、带来源的中英文别名或10位学校标识码，可叠加地区和素材类型。网页不提供采集分类标签筛选；“短校名”“教育部备注为空”等内部标签仍保留在数据文件中。旧地址中的`tag`参数不再参与网页筛选，首次打开会移除该参数。
2. 展开“更多筛选”，选择来源、常用文件格式、标识样式、透明背景、文件记录或配色依据。多个素材条件必须匹配同一记录。HTML、未知格式与示例标记不再作为文件格式选项，原记录仍可在详情及单校JSON中查阅。折叠时显示已启用的条件数；重置筛选会清空条件并收起此区。
3. 点击学校查看标识、配色、模板和介绍。复制或下载该校完整PPT JSON给AI；复制权限受限时展开“查看 / 手动复制单校 JSON”。筛选只影响卡片展示，复制和下载仍保留全部单校记录及出处。
4. 展开每条记录的来源说明，核对采集日期、版本、依据、哈希和使用条件。原文件及发布页通过原来源访问。

地址参数保存学校及筛选，例如`?school=4111010003`，刷新、浏览器后退后可恢复；分页每页24所。地区分包按需载入并在本次打开中缓存，重新打开会读取仓库当前文件。

## 分类与证据

| 展示区 | 分类和使用方式 |
| --- | --- |
| 标识 | 校徽、校名文字、徽名组合、官网页眉待判定、纪念标识；记录来源、格式、尺寸、矢量与透明信息 |
| 配色 | 校方数字色、仅印刷色、设计/社区参考色分组；冲突候选并列显示，屏幕主色暂停选择 |
| 模板 | 学校通用、院系专用、社区主题、适用范围未明确、PPT等视觉文件分别展示 |
| 文件结构 | 实读PPTX显示页数、画幅、声明字体、文本节点、文件哈希；声明字体不等于已安装，画面未渲染不标为逐页预览 |
| 介绍 | 短摘要、校训、建校起点、英文名及检索别名，保留来源时期、统计时间及原始依据 |

官网发布的PPT文件若只包含标识，仍按视觉文件展示，不自动称为通用模板。模板内部主题色不进入学校VI标准色。校方色值只含CMYK/Pantone时，屏幕值保持空白；参考色另列。

## 图形预览

已经实读且提供直接图像网址的常见图形格式自动载入；未读取或历史失败的记录需点击“尝试载入图形”。ZIP成员展示原压缩包与包内路径，不能把ZIP链接作为PNG直链。PDF等不能内嵌的格式提供原来源入口。

深/浅背景和透明棋盘便于比较图形，按反白标签给出的背景只是预览提示。图形从原站载入，不复制为本库资产。首次载入、成功、失败和12秒未完成分别显示；重试可重新载入。网页载入成功不证明学校现行版本或图形授权，失败也不覆盖历史内容已读取的事实。

文字、元数据、检索和色卡可从本地读取；原站图形、链接及模板下载需要网络。浏览器或原站限制可能导致图形无法显示，此时继续查看来源与元数据。暂无图形、配色或模板集合的学校仍在1412所身份范围内，调查状态显式展示。

## 生成与维护

唯一事实源为每校`profile.yaml`，目录来自[PPT导出v1](ppt-export-v1.md)。`viewer/data/catalog.json`约0.95 MB，提供身份及素材匹配描述；31个`provinces/<地区>.json`保留完整单校导出。原导出SHA256写入目录。重复的筛选描述压缩存储，实际候选不合并。

```bash
.venv/bin/python scripts/ingest/build_ppt_profiles.py
.venv/bin/python scripts/ingest/build_viewer.py
.venv/bin/python scripts/ingest/build_viewer.py --check
.venv/bin/python scripts/check.py
```

完整校验需要Python质量依赖与Node.js 24；`--node`可指定不在PATH中的Node。`build_viewer --check`只比较已生成资料，不访问网络或修改文件。新资料或导出变化后先重新生成，禁止手改地区JSON。

## 搜索界面更新验收（2026-10-03）

分类标签筛选已移除，校名、地区和素材类型作为主要入口；页头收紧，学校目录新增标题。来源、格式、样式等条件保留在“更多筛选”中。学校详情中的双一流、民办、合作办学、职业本科等学校属性仍可展示。

本轮在Codex内嵌浏览器实测：PKU匹配并打开北京大学；旧`?query=PKU&tag=private`仍返回北京大学且地址自动去掉`tag`；清华“校方+SVG”返回0所，“社区+SVG”返回1所、详情3条标识。刷新可恢复学校和素材条件；切到配色会清空不适用的图形条件；重置回到1412所且收起更多筛选。1280×900桌面与390×844手机均检查布局，手机内容宽度等于390，没有横向溢出，键盘搜索框焦点可见。

统一质量检查13/13通过，含130项Python测试与13项网页规则测试。此轮没有新增学校事实，也没有重新核对全量远程图形、剪贴板、下载落地或完整无障碍合规。
