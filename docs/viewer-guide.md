# 在线目录使用指南

## 打开和使用

在线使用：[University Design DB](https://yangxiake.github.io/university-design-db/)，无需安装Python或Node.js。公开站点通过GitHub Pages托管，main 更新后由 GitHub Actions 自动检查、构建和部署；详情和页脚的完整档案、说明链接固定到本次部署的源提交。

本地使用时，在下载后的仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开`http://127.0.0.1:8765/viewer/`。静态页面没有npm依赖，也不需要Node.js。通过HTTP读取JSON，直接双击HTML的`file:`方式无法正常载入数据。本机地址只能由本机访问，服务停止后需重新启动。仓库与Release资料包已[公开发布到GitHub](https://github.com/yangxiake/university-design-db)，无需登录即可查看与下载。公开站点部署方法见[GitHub Pages说明](github-pages.md)。

1. 搜索校名、带来源的中英文别名或10位学校标识码，可叠加地区和素材类型。网页不提供采集分类标签筛选；“短校名”“教育部备注为空”等内部标签仍保留在数据文件中。旧地址中的`tag`参数不再参与网页筛选，首次打开会移除该参数。
2. 点击“筛选”，选择来源、常用文件格式、标识样式、透明背景、文件记录或配色依据。多个素材条件必须匹配同一记录。HTML、未知格式与示例标记不再作为文件格式选项，原记录仍可在详情及单校JSON中查阅。已启用条件显示为可移除的标签；“清除全部”清空条件并收起高级筛选。
3. 点击学校查看标识、配色、模板和介绍。复制或下载该校完整PPT JSON，用于演示制作、程序或AI上下文；复制权限受限时展开“查看 / 手动复制单校 JSON”。筛选只影响卡片展示，复制和下载仍保留全部单校记录及出处。
4. 同类标识在一张卡片内切换版本，相同文件合并出处。展开来源说明，核对每条原始记录的采集日期、版本、依据、哈希和使用条件。原文件及发布页通过原来源访问。

地址参数保存学校及筛选，例如`?school=4111010003`，刷新、浏览器后退后可恢复；分页每页24所。地区分包按需载入并在本次打开中缓存，重新打开会读取仓库当前文件。

## 按钮与交互

主要按钮和输入控件桌面高度40px，手机44px；小按钮32px。复制资料为唯一主要操作，下载JSON为次要按钮，学校官网和完整档案为文字链接。手机主要操作两列排列。标识卡片中的版本、原文件、发布来源仍分别可用；完整证据在展开区查看。

悬停、按下、选中、禁用和键盘焦点使用统一颜色。四个资料分区采用标准Tabs，当前分区独立显示；左右方向键循环切换，Home/End定位首尾，地址保留学校与筛选参数。素材类型选择会定位到对应分区。桌面目录独立滚动、底部固定分页；宽度小于900px时通过“选择学校”打开抽屉，Tab焦点留在抽屉内，Escape关闭并返回入口。

控件过渡150ms，折叠160ms，使用同一缓动曲线。快速重复展开会反转到最后请求的状态，结束后不保留内容裁切。浏览器启用“减少动画”偏好时，立即切换折叠状态并关闭页面过渡与平滑滚动。点击色块或“复制”按钮可复制HEX，成功提示包含具体色值；仅印刷色没有可复制的屏幕值。

## 分类与证据

| 展示区 | 分类和使用方式 |
| --- | --- |
| 标识 | 校徽、校名文字、徽名组合、官网页眉待判定、纪念标识；记录来源、格式、尺寸、矢量与透明信息 |
| 配色 | 校方数字色、仅印刷色、设计/社区参考色分组；冲突候选并列显示，屏幕主色暂停选择 |

## 图形预览

已经实读且提供直接图像网址的常见图形格式自动载入；未读取或历史失败的记录需点击“尝试载入图形”。预览同时最多载入3个文件，每次请求开始后最多等待20秒；首个地址失败时，自动尝试同一文件的其他已记录来源。切换学校或版本会取消不再需要的请求。本次已成功载入的图形在筛选重绘时复用；失败记录不会在每次重绘时重复请求，点击“重新尝试”可重试。

ZIP成员展示原压缩包与包内路径，不能把ZIP链接作为PNG直链。PDF页或区域标识提供原PDF入口，不当作独立图片。深/浅背景和透明棋盘便于比较图形；自动模式遵循已有预览提示，透明的官网标识和校名文字默认用深色背景。这只是显示设置，不改变学校色值。网页载入成功不证明学校现行版本或图形授权，失败也不覆盖历史内容已读取的事实。

源仓库可选运行以下无网络脚本，将`tmp/`中已经读取的文件按档案哈希核对后建立本机预览缓存；ZIP成员同时核对压缩包与成员哈希，不提取包内路径到文件系统。SVG需通过本地预览检查。脚本只使用Python标准库，不补采新资料：

```bash
python3 scripts/prepare_viewer_previews.py
```

缓存位于忽略目录`tmp/viewer-previews/`，仅在本地回环地址打开目录时优先使用。本机本次找到1313个匹配文件，覆盖1106所学校的至少一个标识；数量取决于已有本地文件，下载资料包不会附带这些缓存或开发脚本。第三方图形不写入Git或发布包，原来源和权利说明仍保留。

文字、元数据、检索和色卡可从本地读取；没有本机缓存的图形、原链接及模板下载需要网络。浏览器或原站限制仍可能导致预览失败，此时可切换文件版本或查阅原来源与元数据。暂无图形、配色或模板集合的学校仍在1412所身份范围内，调查状态显式展示。

## 重复资源整合

标识先按文件哈希合并多个来源，再按标识样式集中展示不同文件版本。无哈希时以同一文件网址和包内路径判断；同一网址有多个已知哈希时，不猜测未读取记录属于哪个版本。同一PDF的不同页或区域分别保留。同类不同版本集中到一张卡片，不表示它们内容相同，切换时会显示各自的来源和使用条件。

配色只在校方数字色、校方印刷色、设计参考或同一冲突候选组内部整合；色值与RGB、CMYK、Pantone需一致，冲突值不会因HEX相同被覆盖。模板入口按网址、适用范围及版本年份整合；已读取PPTX按文件身份合并，压缩包成员和同哈希直链文件只展示一次并保留全部出处。单校JSON及唯一事实源保留原始记录，合并只影响网页展示。

## 生成与维护

唯一事实源为每校`profile.yaml`，目录来自[PPT导出v1](ppt-export-v1.md)。`viewer/data/catalog.json`约0.95 MB，提供身份及素材匹配描述；31个`provinces/<地区>.json`保留完整单校导出。原导出SHA256写入目录。重复的筛选描述压缩存储，实际候选在导出中完整保留；网页按上述规则整合展示。

```bash
.venv/bin/python scripts/ingest/build_ppt_profiles.py
.venv/bin/python scripts/ingest/build_viewer.py
.venv/bin/python scripts/ingest/build_viewer.py --check
.venv/bin/python scripts/check.py
```

完整校验需要Python质量依赖与Node.js 24；`--node`可指定不在PATH中的Node。`build_viewer --check`只比较已生成资料，不访问网络或修改文件。新资料或导出变化后先重新生成，禁止手改地区JSON。
